STATEMENT: Before the Tower CSCI controls traffic it shall read the airport TOML file and shall refuse to start control when the file is missing, unreadable, or lacks a required airport identity, position, communications distance, computer count, or runway list. STATEMENT: The Tower CSCI shall assign a runway only when its designation allows the intended operation: arrival for landing, departure for takeoff, both for either, and closed for neither. A runway marked not independent shall conflict with every other runway that is not independent, and a runway listed as intersecting another shall conflict with that runway. Acceptance is a closed runway that cannot be assigned, a departure-only runway that rejects a landing, and two non-independent runways that cannot be occupied together.
 RATIONALE: Designation is the policy in the TOML file. The clearance code must not invent a use the file does not allow.
 ASSUMPTIONS: The checked envelope is 4 runways, 8 aircraft under control, and 2 neighbor airports. Visual separation, LAHSO, radar vectoring, TRACON, enroute control, and wake RECAT are outside this increment.
