STATEMENT: The clearance state machine shall use the phases out, queued, hold, occupying, and air. The actions shall be assign, sequence, hold short, line up and wait, takeoff, land, go-around, and handoff, and each action shall match a TLA+ action of the same name in AtcTower. Occupying means the aircraft is inside the protected volume. Acceptance is a review that every Erlang action name appears in the TLA+ spec and that a sampled transition produces the same phase change in both descriptions.
 RATIONALE: The design keeps one action vocabulary so the refinement mapping has something to point at.
 ASSUMPTIONS: The checked envelope is 4 runways, 8 aircraft under control, and 2 neighbor airports. Visual separation, LAHSO, radar vectoring, TRACON, enroute control, and wake RECAT are outside this increment.
